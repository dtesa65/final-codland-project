# 🌍 Глобальное потепление

Информационный веб-сайт, созданный для того, чтобы доступно и понятно осветить основные проблемы, серьезные последствия и реальные пути решения глобального потепления.

## 📖 О проекте
На этом сайте собрана общая структурированная информация о современном изменении климата. Проект помогает пользователям разобраться в том, почему нагревается наша планета, к чему это уже приводит и что каждый из нас может сделать для улучшения ситуации.

### Основные разделы сайта:
* **🔥 Причины и проблемы:** основные факторы, вызывающие парниковый эффект и рост средней температуры на Земле.
* **🌊 Последствия:** влияние потепления на природу, уровень мирового океана, погоду и жизнь людей.
* **🌱 Пути решения:** современные технологии, переход на возобновляемую энергию и полезные эко-привычки на каждый день.

## 🛠 Используемые технологии
* html
* Python (Flask)

## 🚀 Как запустить проект локально
1. Склонируйте репозиторий на свой компьютер:
   ```bash
   git clone https://github.com
   ```
2. Откройте папку с проектом и запустите главный файл `index.html` в любом браузере (или запустите сервер, если сайт написан на Python).
